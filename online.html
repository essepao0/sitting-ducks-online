Online

The PS2 game was never designed for networking. Here is how we make it work, how to play and what is still missing.

How it works

Each player runs their own PCSX2 with the game. A small program next to the emulator (the client) reads and writes the game's memory through PINE, PCSX2's interface for external programs. The client talks to a TCP server.

PCSX2 + game ⇄ PINE ⇄ client ⇄ TCP ⇄ server ⇄ other clients

In each player's game, their own character (P1) is the only authority: feathers, unlocks and profile belong to them. The other players are "puppets": native game characters moved by the client with the data coming from the network, 30 times a second, with 100 ms of interpolation to keep them smooth.

When you join, the whole town map is preloaded, so everyone always has the same areas in memory. Traffic spawns from the same points with the same random generator, which is why people and vehicles match in every client.

How to play and host

Step by step, with launcher screenshots: Tutorial → Playing online. In short: Entra (Join) connects you to a server, Ospita e gioca (Host and play) creates one (TCP port 28022), and R3 + UP in game opens the online menu.

Game rules

  • Missions: whoever starts the mission is brought to the start first, then the others. If one player wins, everyone wins. During the mission, a player who strays too far or disconnects makes everyone lose.
  • Cutscenes and end screens: skipping or confirming counts for everyone. Saving is always skipped online.
  • Dropped feathers: they belong to whoever picks them up first, even if they were someone else's.
  • Vehicles: a vehicle is one and the same for everyone. If you take it, the others see you driving.

Current limits

  • The game has 4 native player slots: with 5 or more, some buildings are not drawn. The server accepts up to 20 connections.
  • Several parts of the client still handle only one remote player. Work to reach 4 is under way.
  • The handlebars of scooters driven by other players don't turn.
  • Remote crocodile chase animation has a new correction under test. Restart the game with the updated source launcher; an older emulator state retains the old code. Test status.
  • Switching Bill / Aldo for remote players is being tested.
  • The Windows version hasn't been tested on a real Windows PC yet.
  • After a crash or a forced shutdown, restart PCSX2 before joining again.
