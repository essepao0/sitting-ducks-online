Installing the mod

1. What you need

  • PCSX2 (tested with v2.9).
  • Your own copy of Sitting Ducks for PS2, European release SLES-52116, as an ISO. The launcher needs the modified ISO (van and no startup logos): the tool that builds it from your copy is in the works.
  • Your PS2's BIOS.

We do not distribute the game, the BIOS or extracted files.

2. Download and open the launcher

  • macOS: download Sitting-Ducks-Online-macOS-arm64.zip from the Releases page, unzip it and open Sitting Ducks Online.app. The first time, right-click → Open, because the app isn't signed.
  • Windows: unzip the whole folder, not just the .exe, and open Sitting Ducks Online.exe. From the sources, gioca_online.bat downloads and verifies Python on its own the first time.

3. Setup

Open the Configurazione (Setup) tab and use Scegli… (Choose) to pick PCSX2 (the .app bundle on Mac), the ISO and the BIOS. Then press Salva configurazione (Save). The launcher sets memory, patches and the link to the game on its own.

4. Ready

The Gioca (Play) tab now says «Pronto.» (Ready). Name, address and paths are remembered for next time. Launcher data lives in ~/Library/Application Support/Sitting Ducks Online/ (Mac) and %LOCALAPPDATA%\Sitting Ducks Online\ (Windows): Apri dati (Open data) opens the folder.

Playing online

1. Join a server

In the Gioca (Play) tab, type your name plus the address and port the host gave you (default port 28022), then press Entra (Join).

2. Load a game

PCSX2 starts on its own. Load a save or start a new game: you get connected once you are freely exploring the town. The other players appear next to you.

3. The online menu

In game, R3 + UP opens the online menu: UP/DOWN to choose, RIGHT to confirm. From here you can disconnect without closing the game. Leaving the game also disconnects you.

4. Leaving

Disconnetti (Disconnect), in the launcher or in the R3 + UP menu, closes the connection cleanly. The game stays open and Entra reuses it.

Hosting a game

  1. In the Gioca (Play) tab press Ospita e gioca (Host and play): the launcher starts the server and joins it. Host settings (feathers, unlocks, day and night, passers-by, players) are in the R3 + UP menu during the game.
  2. The Server tab shows the status and the connected players. Avvia solo server (Start server only) works even without the game; Nuova campagna (New campaign) restarts the shared missions from scratch.
  3. Give your friends your computer's address:
    • Same home network: the local address (for example 192.168.1.20).
    • Over the Internet: a group VPN (for example Tailscale or ZeroTier), or TCP port 28022 forwarded from your router to your PC.

Two players on the same computer? Nuova sessione (New session) opens a second launcher with its own PCSX2 and profile. The Istanza PCSX2 (PCSX2 instance) menu attaches a PCSX2 window that is already open.

Rejoin without using the launcher window testing

  1. Keep the updated source launcher running in the background. Disconnect and wait for the offline game to be restored.
  2. Open R3+UP and choose Entra on the last server, or Rientra nel server on the first row.
  3. You can repeat this cycle; the launcher also recognises the new connection and its Disconnetti button works.

This Python change needs a newly opened launcher to take effect; normal reconnection does not restart the game. If the loaded game patch differs from the package, a full game boot is still required. Client and server must use matching versions. Visual confirmation with two players is pending.

If something goes wrong

  • Apri registro (Open log) shows the session log: send it along when you report a bug.
  • After a crash or a forced shutdown, restart PCSX2 before joining again.
  • Friends can't join? Check the address, port and VPN, or the forwarding of port 28022.
