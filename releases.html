Online interactions — schema 15 testing

After the input correction, the user reported a crash/disconnection for all players, including on foot without a skateboard. Logs show an accepted empty push followed by an invalid game handle; the server stays running. The reverse clip could remain active after its timeout. The new candidate plays the same native movement forward and explicitly restores idle after the push, preserving damage and vehicle actions. Owning a skateboard is not required. The connection fix still needs in-game confirmation.

Follow-up: both clients logged at least 28 pushes, six targeting NPCs, without another disconnect. RAM samples show forward playback and return to idle. This is runtime evidence for the observed sequence; visual confirmation and the remaining interaction checks are pending.

The first user trial still found no push. The controller row had been confused with the gameplay context: Circle is row+1D, whereas context+2D is its edge. The same error made passenger boarding read Circle and a timer as L1+Triangle. The new regression executes the original pad decoder; this correction needs another full restart and remains under testing.
